==========================================================
Fingerspot Attendance Machine Integration + Operating Unit
==========================================================

Glue module that adds Operating Unit support to the Fingerspot Attendance
Machine Integration module. Extends ``fingerspot.attendance.machine.batch``
with ``mixin.single_operating_unit``, so that attendance machine batches can
be scoped and restricted per operating unit.


Installation
============

This module depends on:

* ``ssi_fingerspot``
* ``ssi_operating_unit_mixin``
